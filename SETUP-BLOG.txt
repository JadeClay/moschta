========================================
MOSCTHA BLOG - SETUP INSTRUCTIONS
========================================

Follow these steps one time on your cPanel hosting.


----------------------------------------
STEP 1: Create MySQL Database
----------------------------------------

1. Log in to cPanel
2. Go to "MySQL Databases"
3. Under "Create New Database", enter a name (e.g. moschta_blog)
   - Full name will be: yourcpaneluser_moschta_blog
4. Click "Create Database"

5. Under "MySQL Users" > "Add New User", create a user:
   - Username: (e.g. blog_admin)
   - Password: (generate a strong password, save it somewhere)
   - Click "Create User"

6. Under "Add User To Database":
   - Select the user you just created
   - Select the database you just created
   - Click "Add"
   - Check "ALL PRIVILEGES"
   - Click "Make Changes"


----------------------------------------
STEP 2: Create the blog_posts Table
----------------------------------------

1. Go to "phpMyAdmin" in cPanel
2. Click on your database name in the left sidebar
3. Click the "SQL" tab at the top
4. Paste the following SQL and click "Go":

----------------------------------------

CREATE TABLE blog_posts (
  id INT AUTO_INCREMENT PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  date DATE NOT NULL,
  excerpt TEXT NOT NULL,
  image_url VARCHAR(500) DEFAULT '',
  content LONGTEXT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

----------------------------------------


----------------------------------------
STEP 3: Edit api.php
----------------------------------------

Open the file api.php in your site's root directory and
replace these lines near the top:

  define('DB_NAME', 'YOUR_DATABASE_NAME');
  define('DB_USER', 'YOUR_DATABASE_USER');
  define('DB_PASS', 'YOUR_DATABASE_PASSWORD');

  define('ADMIN_EMAIL', 'moschta@gmail.com');
  define('ADMIN_PASSWORD', 'CHANGE_THIS_PASSWORD');

With your actual values:

  DB_NAME = the full database name from Step 1
             (e.g. yourcpaneluser_moschta_blog)

  DB_USER = the username from Step 1
             (e.g. yourcpaneluser_blog_admin)

  DB_PASS = the password you set for that user

  ADMIN_EMAIL = the email you want to log in with

  ADMIN_PASSWORD = a strong password for the admin panel
                   (NOT your database password, pick something new)


----------------------------------------
STEP 4: Image Upload Setup
----------------------------------------

The blog supports uploading images directly from the admin panel.
Two things need to be checked on cPanel after uploading:

1. uploads/ DIRECTORY PERMISSIONS
   - The "uploads" folder must be writable by PHP.
   - In cPanel > File Manager, right-click "uploads" > Change Permissions
   - Set it to 755 (owner: read/write/execute, group/others: read/execute)
   - If uploads still fail, try 777 as a fallback

2. PHP UPLOAD FILE SIZE LIMIT
   - By default, PHP limits uploads to 2 MB (upload_max_filesize).
   - The blog allows up to 5 MB images.
   - To increase it:
     a. In cPanel, go to "MultiPHP INI Editor" or "Select PHP Version"
     b. Find "upload_max_filesize" and set it to at least "5M"
     c. Also check "post_max_size" is set to at least "6M"
     d. OR create/edit a .user.ini file in your site root with:
          upload_max_filesize = 5M
          post_max_size = 6M

After both checks, you can upload JPG, PNG, GIF, and WebP images
(up to 5 MB) directly from the admin panel.


----------------------------------------
STEP 5: Done - Start Posting
----------------------------------------

1. Go to: https://yoursite.com/admin.html
2. Log in with the ADMIN_EMAIL and ADMIN_PASSWORD from api.php
3. Click "+ New Post"
4. Fill in title, date, excerpt, and use the editor for content
5. Click "Save Post"
6. Your post appears on the blog page automatically

Visit https://yoursite.com/blog.html to see your posts.
Visit https://yoursite.com/post.html?id=1 to see a single post.


----------------------------------------
SECURITY NOTES
----------------------------------------

- Enable HTTPS in cPanel (usually free via Let's Encrypt)
- Keep your ADMIN_PASSWORD strong and private
- The database user only needs access to this one database
- api.php requires login for create/update/delete operations
- Only the post listing (GET) is public - no sensitive data exposed
